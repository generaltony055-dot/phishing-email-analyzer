\# Phishing Email Analyzer

A Python and Flask-based cybersecurity project that analyzes `.eml` email files for potential phishing indicators.


\## Features:

\- Parses `.eml` email files
\- Extracts sender, recipient, subject, and email body
\- Extracts URLs from email content
\- Checks URLs for basic suspicious indicators
\- Detects suspicious or urgent language
\- Analyzes sender addresses
\- Calculates an explainable risk score
\- Classifies the result as LOW, MEDIUM, or HIGH
\- Provides a browser-based interface using Flask


\## How It Works:

The analyzer examines multiple signals from an email:

Important Limitations

This project is an educational cybersecurity tool and is not a replacement for a commercial email security gateway or professional threat-intelligence platform.

The current detection rules are heuristic. For example, a hyphen in a domain does not by itself prove that a URL is malicious.

The risk score should therefore be interpreted as an indicator generated by this project, not as a definitive determination that an email is phishing.
